# Dashboard de Análise de Escolaridade e Desemprego

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de analisar a relação entre escolaridade e desemprego no Brasil utilizando dados públicos do IBGE.

A aplicação permite explorar informações por meio de visualizações interativas, facilitando a identificação de padrões, tendências e possíveis correlações entre nível de instrução e indicadores de desemprego.

O projeto foi desenvolvido como atividade acadêmica da disciplina de Modelagem de Dados e Programação Estatística.

---

## 🚀 Tecnologias Utilizadas

* Python
* Pandas
* Plotly
* Streamlit
* NumPy
* Dados do IBGE

---

## 📊 Funcionalidades

* Importação e tratamento de dados do IBGE
* Limpeza e transformação dos dados
* Análise exploratória dos indicadores
* Visualização interativa através de gráficos
* Indicadores estatísticos
* Navegação dinâmica utilizando Streamlit

---

## 📈 Visualizações Disponíveis

* Evolução temporal dos indicadores
* Comparação entre níveis de escolaridade
* Gráficos interativos
* Indicadores resumidos
* Mapas e análises visuais dos dados
